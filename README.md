# Archeos

Landing page Vite + Tailwind CSS pour la chaîne YouTube Archeos.

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Publication GitHub

```bash
git init
git add .
git commit -m "Initial Archeos landing page"
git branch -M main
git remote add origin https://github.com/<utilisateur>/<repo>.git
git push -u origin main
```

Remplace `<utilisateur>` et `<repo>` par le compte et le dépôt GitHub.
